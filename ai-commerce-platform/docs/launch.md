# قائمة الإطلاق في السوق (Launch Checklist)

المنصة جاهزة تشغيلياً كدورة دروب شيبينج كاملة (نمط مساعَد + محاكاة). قبل الإطلاق
التجاري الحقيقي هناك خطوات تعتمد على حسابات وخدمات لا يمكن إنجازها من داخل الكود.

## ما هو **جاهز** الآن

- متجر عربي RTL بعملة الجنيه المصري، بحث ومساعد ذكي وتوصيات.
- تسجيل/دخول، سلة، checkout بالدفع عند الاستلام (COD).
- دورة دروب شيبينج كاملة: وكيل توريد آلي → موافقة مشغّل → شراء → شحن → تسليم.
- لوحة إدارة للمشغّل + تتبّع طلب معقّم للعميل.
- كل شيء يعمل بأمر `docker compose up` + `make seed`.

## ما **يتطلب إجراءً منك** قبل الإطلاق

### 1) البنية والاستضافة
- [ ] اسم نطاق (دومين) + إعداد DNS.
- [ ] استضافة (VPS/سحابة) تشغّل `docker compose`، مع HTTPS (Let's Encrypt/Caddy/Nginx).
- [ ] ضبط `NEXT_PUBLIC_API_URL` على دومين الـ API الحقيقي، و`BACKEND_CORS_ORIGINS` على دومين المتجر.
- [ ] نسخ احتياطي دوري لقاعدة PostgreSQL.

### 2) الأمان (إلزامي)
- [ ] توليد `SECRET_KEY` قوي: `openssl rand -hex 32` (لا تترك القيمة الافتراضية).
- [ ] كلمات مرور قوية لقاعدة البيانات، وعدم كشف منفذ Postgres للإنترنت.
- [ ] تغيير كلمات مرور الحسابات التجريبية (demo/admin) أو حذفها وإنشاء حساب إداري حقيقي.
- [ ] مراجعة `.env` — لا يُرفع إطلاقاً إلى Git (مضمّن في `.gitignore`).

### 3) الدفع الإلكتروني (اختياري للإطلاق — COD يكفي للبدء)
- [ ] فتح حساب تاجر لدى بوابة (Paymob شائعة في مصر، أو Stripe).
- [ ] تنفيذ `authorize()` في adapter داخل `backend/app/services/payments.py`.
- [ ] ضبط `PAYMENT_PROVIDER=gateway` ومفاتيح المزود في `.env`.
- [ ] اختبار في وضع sandbox قبل التحويل للإنتاج.

### 4) الموردون (الدروب شيبينج)
- [ ] حسابات شراء فعلية لدى جوميا/أمازون/نون لتنفيذ الطلبات (النمط المساعَد).
- [ ] لأتمتة كاملة: حسابات أعمال/شركاء + APIs رسمية → connectors (انظر `docs/dropshipping.md`).
- [ ] الالتزام بشروط خدمة كل مورد — **لا سكرابنج/بوتات checkout**.
- [ ] ضبط `MARGIN_MIN_PERCENT` بما يناسب هوامشك، وتحديث عروض الموردين بأسعار حقيقية.

### 5) الجوانب القانونية والتشغيلية (استشر مختصاً)
- [ ] سجل تجاري وضريبي حسب قوانين مصر، وسياسة أسعار شاملة الضرائب.
- [ ] صفحات: سياسة الخصوصية، الشروط والأحكام، سياسة الاستبدال والإرجاع، بيانات التواصل.
- [ ] الامتثال لحماية بيانات العملاء، وتأمين شركة شحن/لوجستيات موثوقة.
- [ ] خدمة عملاء (النمط المساعَد يتطلب مشغّلاً يتابع الطلبات يومياً).

> ملاحظة: هذه قائمة إرشادية عامة وليست استشارة قانونية أو محاسبية. راجع مختصاً محلياً.

## بعد الإطلاق
راقب مؤشرات: معدل التحويل، متوسط قيمة الطلب، السلة المتروكة، هامش الربح الفعلي مقابل
المتوقع (من لوحة الإدارة)، ونسبة أوامر "بانتظار التوريد" (تشير لنقص عروض موردين).
